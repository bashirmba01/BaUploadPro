# fbUploadPro — Facebook Auto Publisher
Auto post, schedule & manage Facebook pages via Meta Graph API + Session Capture.

## Features
- ✅ Facebook OAuth — Pages auto-connect
- ✅ Chrome Extension — Session capture
- ✅ Auto Publishing Worker — Text/Photo/Video/Reel
- ✅ Content Queue — Schedule posts
- ✅ Wallet & Top-up System
- ✅ Admin Panel — Top-up approvals
- ✅ Real Graph API Sync

## Setup
1. Copy `.env.example` → `.env` & fill values
2. Run `bun install`
3. Run `bun dev`
4. Open Supabase SQL Editor → run both `.sql` files
5. Set Meta App Redirect URIs
6. Deploy & set CRON job
